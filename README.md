# World Cup Database

This project uses PostgreSQL to store and analyze World Cup match data.

## Files

- `worldcup.sql` — Creates the database tables and imports the World Cup data.
- `insert_data.sh` — Inserts teams and games into the database.
- `queries.sh` — Runs SQL queries to analyze World Cup match statistics.

## Technologies

- PostgreSQL
- SQL
- Bash scripting
- Git and GitHub

## What I Learned

- Creating relational database tables and using primary and foreign keys.
- Inserting data while avoiding duplicate teams.
- Using SQL joins, aggregate functions, filtering, and sorting.
- Automating database operations with Bash scripts.
